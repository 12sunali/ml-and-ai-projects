# NLP Text Preprocessing using NLTK

This project performs text preprocessing on TripAdvisor hotel reviews using Python and NLTK.

## Steps Performed

- Convert text to lowercase
- Remove stopwords
- Remove punctuation
- Tokenization
- Stemming
- Lemmatization
- Generate Unigrams
- Generate Bigrams
- Generate 4-grams

## Libraries Used

- pandas
- nltk
- re

## Dataset

TripAdvisor Hotel Reviews Dataset

## How to Run

```python
pip install nltk pandas
```

Then run notebook:

```python
jupyter notebook tokenization.ipynb
```

## Output

The notebook generates:

- Tokenized text
- Stemmed words
- Lemmatized words
- Unigrams frequency
- Bigrams frequency
- 4-grams frequency

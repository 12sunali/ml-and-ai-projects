# 🤖 AI Interview Chatbot

An AI-powered HR Interview Simulator built using Streamlit and Groq (FREE LLM API).

The chatbot:
- conducts an interview
- asks questions
- limits responses
- generates final score + feedback

## Features

- AI HR Interviewer  
- Candidate setup form  
- Role and company selection  
- Chat-based interview UI  
- Limited interview questions  
- AI evaluation & scoring  
- Interview feedback generator  
- Restart interview button  
- FREE Groq API  

## Installation

```bash
pip install streamlit groq streamlit-js-eval
